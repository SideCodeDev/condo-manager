# Condo Management

A modern web-based platform for managing residential condominiums, designed to simplify administration, communication, and transparency between administrators and residents.

This project is an **MVP (Minimum Viable Product)** focused on solving real-world condominium management problems, especially within the Portuguese context.

---

## 🚀 Project Goals

- Centralize condominium information in one place
- Improve communication between administrators and residents
- Simplify quota tracking and document management
- Provide a clean, modern, and easy-to-use interface

---

## 🧩 Core Features (MVP)

- User authentication (Administrator / Resident)
- Condominium and unit (fraction) management
- Manual quota tracking (paid / pending)
- Shared document repository (minutes, rules, budgets)
- Notices and announcements
- Issue / occurrence reporting
- Simple dashboards for administrators and residents

---

## 🛠 Tech Stack

- **Frontend & Backend**: Next.js
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL
- **ORM**: Prisma
- **Auth**: NextAuth / custom auth
- **Infrastructure**: Docker
- **Deployment**: Vercel (planned)
