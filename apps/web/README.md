# Condo Manager Web App

Authenticated React 19 + Vite application using Clerk for identity and Convex
for application data. Shared components and design tokens come from
`@condo-manager/ui`.

## Setup and run

From the monorepo root, install dependencies and create `apps/web/.env` from
`.env.example`:

```dotenv
VITE_CLERK_PUBLISHABLE_KEY=
VITE_CONVEX_URL=
```

For the deployed app to sync development-instance Clerk sessions from the
website, configure it as a satellite with `VITE_CLERK_IS_SATELLITE=true`,
`VITE_CLERK_DOMAIN=app.condo.sidecode.pt`, and sign-in/sign-up URLs pointing to
`https://condo.sidecode.pt/sign-in` and `/sign-up`. The website's
`VITE_CLERK_ALLOWED_REDIRECT_ORIGINS` should include
`https://app.condo.sidecode.pt`. Add `app.condo.sidecode.pt` as a satellite in
the Clerk development instance. For local development, use the corresponding
localhost origins and ports instead.

Then start the app:

```sh
pnpm dev:web
```

The Clerk key and Convex URL are client-visible configuration. Never put
`CLERK_SECRET_KEY` or webhook secrets in a `VITE_*` variable.

## Integration notes

- `src/main.tsx` composes `ClerkProvider`, `ConvexProviderWithClerk`, and the
  TanStack Router provider.
- Routes live in `src/routes`; `src/routeTree.gen.ts` is generated by the Vite
  TanStack Router plugin.
- Authorization must still be enforced in Convex functions, regardless of what
  the client renders.
- `@condo-manager/ui/styles.css` is imported once by `src/main.tsx`.

## Checks

```sh
pnpm --filter @condo-manager/web build
```
